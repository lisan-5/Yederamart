# Meski Visions Guide

Local development and deployment instructions for this Vite + React project.

## Quickstart

1. Install dependencies:

```sh
npm install
```

2. Start development server:

```sh
npm run dev
```

3. Build for production:

```sh
npm run build
```

## Technologies

- Vite
- React
- TypeScript
- Tailwind CSS

## Notes

- If you previously used any external tooling, it has been removed from this repo. Use the standard npm workflow above.
